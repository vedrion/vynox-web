02

Media specs — export before you upload

Every video and image on the site is exported to a fixed recipe. Match it and the page stays fast; ignore it and one file can add seconds to the load.

Video

Setting Use
Container .mp4
Codec H.264 — the one format every browser plays
Frame rate 30 fps
Resolution 720p — 1280×720 landscape, 720×1280 for vertical reels
Audio None. Strip the track entirely — every video on the site plays muted

Images

Setting Use
Format .avif — same picture, a fraction of the file size
Resolution 720p class — no wider than the slot the image sits in
File size Under roughly 300 KB

Anything larger is wasted. The site never renders a reel above 720p, so a 4K upload downloads in full and is then scaled down on the viewer’s screen. Export to spec first, then drop the file into public/ and point the key in src/config/assets.ts at it.

03

Content — the files you’ll actually edit

All site copy lives here. Nothing in this folder controls layout, so you cannot break the design by editing it.

File Holds
src/content/home.ts Every home-page section: hero, brands strip, video, services list, stats, “sets apart”, case-studies band, testimonials
src/content/services.ts All four service pages, keyed by URL slug — hero, problems, solutions, stats, closing CTA
src/content/case-studies.ts Featured cases, the full campaign grid, and the long-form detail page for each case
src/content/creators.ts Creator roster in the carousel — name, follower count, tags, photo key
src/content/testimonials.ts Client quotes, author names, roles, photo keys
src/content/about.ts About hero, the “we shape them” block, team member cards
src/content/legal.tsx Privacy Policy (10 sections) and Terms of Service (15 sections)
src/content/contact.ts Contact page copy, form labels, tab names, dropdown options, time slots, validation messages, and confirmation email wording
src/content/careers.ts Careers page copy, headings, and action labels
src/content/site.ts Navigation, footer, shared company contact details, page metadata, and not-found copy
src/content/service-illustrations.ts Text and labels displayed inside service page illustrations

When editing: keep the surrounding quotes and commas intact, don’t rename the keys to the left of a colon, and don’t delete a field — empty it instead ("").

Folder Holds

Replacing an image: drop the new file into the same folder, then point the matching key in src/config/assets.ts at it. Keep new images under roughly 300 KB — oversized files are the single most common cause of a slow page.

11

Running it

pnpm install          # once
cp .env.example .env # then fill in the Resend key
pnpm dev          # http://localhost:3000

Before publishing, both of these must pass:

pnpm typecheck
pnpm build

The site is fully static — every page is pre-rendered at build time, so it loads fast and reads cleanly to search engines. New services and case studies are picked up automatically on the next build.
